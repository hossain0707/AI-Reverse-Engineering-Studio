# Changelog

## 0.1.0 — Engineering preview

- Native cross-platform desktop interface with six analysis views.
- Bounded PE, ELF, Mach-O binary metadata inspection.
- SHA-256, entropy, section metadata, printable-string filtering and local observations.
- Optional Capstone entry-point disassembly.
- Optional, explicitly approved Ghidra headless function export/decompilation.
- Optional local Ollama AI explanation with bounded untrusted context.
- JSON and Markdown reporting plus a command-line interface.
- Native GitHub Actions build workflows for Windows, macOS and Linux.

Not yet certified as hardened production security software; see [SECURITY.md](SECURITY.md).

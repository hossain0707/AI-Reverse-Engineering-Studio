# Contributing

1. Open an issue describing a concrete bug, usability problem, or proposed feature.
2. Fork the project and develop in a focused branch.
3. Include focused tests for parser and reporting changes.
4. Run `python -m pytest -q` and `python -m ruff check .` before requesting review.
5. Do not check in proprietary binaries, credentials, malware, or decrypted intellectual property.
6. Keep documentation professional and update the threat model for any external integration.

For security issues, follow [SECURITY.md](SECURITY.md) instead of filing a public issue.
